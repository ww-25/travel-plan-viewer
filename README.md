# 威海海岸行程簿

一个从 `dist/威海国庆自驾计划_2026-10-03至10-05.md` 动态读取行程的静态网页应用。

## 功能模块

1. **Markdown 数据层**：解析日期标题、时间段、行程名称和说明；修改 Markdown 后刷新页面即可更新。
2. **可视化时间轴**：按 10 月 3 日、4 日、5 日切换，显示时间、详情与位置。
3. **完成状态**：每段行程均可勾选，状态保存在浏览器 `localStorage`。
4. **进度概览**：显示已完成数量、百分比和环形进度。
5. **地图导航**：地点可选择高德地图、百度地图或 Apple 地图，手机端优先唤起相应 App。
6. **响应式界面**：适配手机与桌面，支持键盘焦点和减少动画偏好。
7. **错误处理**：Markdown 文件读取失败时显示原因与重试入口。

## 本地运行

浏览器出于安全限制不能直接通过 `file://` 读取相邻 Markdown 文件，需要在项目目录启动一个本地网页服务：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。
